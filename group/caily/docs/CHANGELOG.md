# 変更履歴

## 2.3.17 — 2026-10-28
- 共通設定に「メンテナンス」を追加しました。有効にすると、管理者以外はシステムを利用できず、メンテナンス画面が表示されます。管理者はログインして通常どおり操作でき、同じ画面から解除できます。

## 2.3.11 — 2026-10-23
- 建物一覧の「列の表示」に「納期」を追加しました。未完了の子案件ごとに、CAILY納期・GUIS納期・期限日のうち最も近い日時と、依頼相当の部門ラベル・受注形態ラベルを行ごとに表示します。
- 建物一覧の表で横スクロールできるようにし、案件一覧と同様に Space＋ドラッグで横スクロールできます。スクロール時に表ヘッダーが固定表示されます。

## 2.3.10 — 2026-10-23
- 案件一覧の編集モーダル・建物詳細の案件追加/編集モーダルで、「設備図」「意匠図」「配置図」の【メモ】が選択に応じて表示・非表示にならない問題を修正しました（Bootstrap の d-flex が原因）。

## 2.3.09 — 2026-10-23
- 案件一覧の編集モーダルで、「設備図」「意匠図」「配置図」の選択を外しても【メモ】欄が残る問題を修正しました。

## 2.3.08 — 2026-10-23
- カスタム項目「設備図」「意匠図」「配置図」で、セットに無い古い値（例: GUIS）が残ったまま〇を選ぶと履歴が「GUIS → GUIS,〇」になる問題を修正しました。選択肢に無い値は読み込み・保存時に除外し、履歴は「null → 〇」など実際の変更だけを記録します。

## 2.3.07 — 2026-10-23
- 案件詳細・案件一覧の編集モーダル・建物詳細の案件追加/編集モーダルで、カスタム項目「設備図」「意匠図」「配置図」はセットの選択肢のまま使え、値を選ぶと【メモ】入力欄が表示されるようにしました。

## 2.3.06 — 2026-10-21
- 案件一覧で表を下にスクロールしたあと、フローティングの「高度なフィルター」を押しても内容が空になる問題を修正しました。

## 2.3.05 — 2026-10-21

## 2.2.44 / プロジェクト画面の高速化 — 2026-09-10
案件の**一覧**と**詳細**が、以前より軽く・速く開けるように整えました。

**案件一覧**

- 開いたときに同じデータを何度も取りに行かないようにしました。
- 最初に必要なものだけ読み、Excel出力・クイック編集・案内ツアーなどは使うときだけ読みます。
- 画面の文字や見た目の読み込みも整理し、待ち時間を減らしました。

**案件詳細**

- 開いた直後にまとめて読んでいた部品（編集用エディタやコメントなど）を、必要なタイミングまで後ろに回しました。
- 同じ部品を二重に読み込んでいたところをやめました。
- 担当者名や作業量の表示用に、重いデータの代わりに軽い取り方に切り替えました。
- 関係するデータを、できるだけ同時に取りに行くようにしました。
