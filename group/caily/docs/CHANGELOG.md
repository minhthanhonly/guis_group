# 変更履歴

## 2.3.22〜2.3.76 — 2026-11-11〜2026-11-20
この期間の主な変更をまとめました。

**AIアシスタント**
- 申請フォーム（閲覧権限の範囲内）の検索、月・期間ごとの休暇取得者と日数の回答に対応しました。
- 設定が読み込まれない・応答が空になる場合に、原因が分かるメッセージを返すようにしました。

**メモボード**

- 案件詳細のメモを、背景色と公開範囲（全員／自分のみ）を選べるボード形式にしました。
- 3列のグリッドに自由に配置でき、並び順はユーザーごとに保存されます。ピン留めしたメモは上部にまとめて表示されます。
- 全画面表示（F12 キー、案件一覧のメモ欄からも開けます）と全文表示の切替を追加しました。
- 同時に編集できるのは1人だけになりました。編集中のユーザー、最終編集者と日時を表示します。
- 案件一覧のメモ欄もメモボードと同じ並び順・色で表示します。ダークモードでも色付きの文字が読めるようにしました。

**決済情報（見積・請求）**

- 見積・請求を明細（複数行）で入力できるようにしました。売上統計・請求済み案件・建物詳細も明細ベースで集計します。
- 省エネ部署の案件に注文書（申請費／設計費）を追加しました。注文書がない請求は発行済にできません。
- 明細の状態を色付きのドロップダウンにし、「明細を追加」「見積からコピー」をボタンにしました。発行済に切り替えるときは確認を求めます。
- 見積日・請求日に時刻（時:分）を入力できるようにしました（新規は 18:00、「今日」ボタンは現在日時）。ベトナム語表示ではベトナム時間で表示・入力します（保存は日本時間）。
- 東建の省エネ案件では、見積・請求の初期行を申請費の1行だけにしました。
- カードと履歴の表示を整理し、履歴は日付ごとにまとめて種類で絞り込めるようにしました。

**月次売上統計・月次締め**

- 部署・月ごとに月次締めができるようになりました。締め済みの月の請求は追加・変更できず、発行済の請求も変更できません。
- 対象月の選択を年ごとにまとめ、データのある月が分かるようにしました。
- 「未見積」タブを追加し、全タブを1つの Excel にまとめて出力できるようにしました。無償案件の扱いを統一しました。
- 未請求案件は請求待ちの案件だけを表示し、状態の列を追加しました。
- 省エネ部署では担当・チーム列の代わりに担当者（案件のマネージャー）列を表示し、担当別サマリーを非表示にしました。

**案件一覧**

- 高度なフィルターに担当者（部署のユーザー、案件のメンバー・管理者）を追加しました。値が入っている欄は強調表示されます。
- 会社名を入力して部分一致で絞り込めるようにしました。フィルターは部署ごとに保存されます。
- 省エネ部署では高度なフィルターを簡素化し、タスク期限で日付検索できるようにしました。「省エネ向け資料」列も追加しました。
- 読み込み中は全画面に表示するようにしました。更新ボタンをなくし、5分ごとに自動で再読み込みします。
- 横スクロールのカクつき、列幅の崩れ、Excel 出力の遅さ（全行を描画せずに出力）を改善しました。
- Space を押している間、ドラッグスクロールのヒントを表示します。
- 「案件情報をコピー」の形式を見直しました（先頭に ID。省エネは支店名・お施主様名・規模・計算書作成納期・URL）。

**案件詳細・案件フォーム**

- 案件詳細を読み取り専用の表にし、セクションごとに2列で表示するようにしました。入力済みの項目だけを表示し、編集はダイアログで行います。
- 案件の作成・編集ダイアログを、案件詳細・案件一覧・建物詳細で共通にしました。
- 省エネの項目を建物から省エネの子案件に移しました。省エネ部署では CAILY納期・GUIS納期・進捗率を表示しません。
- 省エネ向け資料はチェックボックスで、すべての選択肢を表示します。既定タスク状況はタスクへのリンク付きの表になりました。
- コメントが空のときは折りたたみ、履歴はモーダルで表示します。
- 部署の休暇予定（今後14日間）のパネルを追加しました。
- 案件を完了にしたとき、実終了日が未入力なら自動で保存します。
- 子案件を「案件をコピー」して、同じ建物に新しい案件依頼を作成できるようにしました。

**建物**

- 親案件に複数の顧客を登録し、そのうち1人を主顧客にできるようにしました。
- 建物の登録・コピーを、create.php ではなく建物編集と同じモーダルで開くようにしました。
- 建物詳細の案件依頼を案件ごとのカードにし、部署・ステータスで絞り込めるようにしました。
- 建物一覧を画面幅に収まるように整理しました（関連する列を統合、支店名を別列に分離、メモ列を拡大）。
- 依頼の「その他」を廃止しました（既に「その他」がある建物では表示され、外すことができます）。

**顧客検索**

- 会社名・支店名を入力して絞り込めるようにしました（東建・大東・ナミキを先頭に表示）。
- 検索条件はモーダルを閉じても残ります。検索結果から顧客の詳細を開けるようにしました。
- 「新規顧客」ボタンから顧客を登録し、そのまま顧客リストに追加できるようにしました。

**タスク・全タスク一覧**

- タスク一覧をカンバン表示（閲覧専用）にし、自分の部署を初期表示にしました。フィルターの状態は保存されます。
- 全タスク一覧の初期表示をリストにし、ステータスフィルターと Excel 出力（タイトル・抽出条件・出力日時付き）を追加しました。
- 図面数の代わりに作業比重（%）を表示します。部署フィルターには所属部署だけを表示します（administrator は全部署）。
- タスクを完了にした日時を保存し、一覧のステータスの下に表示します。

**作業比重・既定タスク**

- 省エネの既定タスクは建物の会社名で切り替わります（大東4件／東建3件）。新規案件だけに自動で作成します。
- 既定タスクの固定比率（15%／20%）をやめ、作業比重（整数）から比率を自動計算するようにしました。既存の案件は従来の比率のままです。

**同時編集・データ保護**

- 建物・案件を複数人で同時に編集したとき、他のユーザーの変更を上書きしないようにしました。競合しても入力内容は残ります。
- 案件の詳細・一覧・タスク画面で、データが消える・状態がずれる不具合を修正しました。
- セキュリティを強化しました（API の権限チェック、アップロード、入力値の検証など）。

**統計・権限**

- 従業員統計は、業務担当権限「統計」を持つユーザーにも表示します。全部署を選べるのは administrator だけです。
- チーム売上目標の設定は administrator だけが表示・保存できます。

**画面全体**

- サイト全体の文字サイズを変更できるズーム（スライダー・数値入力・＋／−ボタン）を追加しました。
- 標準のテーマをセミダークに変更し、左メニューのロゴを常に白で表示します。
- 案件詳細・建物詳細のベトナム語訳を完成させました。

## 2.2.44 / プロジェクト画面の高速化 — 2026-09-10
案件の**一覧**と**詳細**が、以前より軽く・速く開けるように整えました。

**案件一覧**

- 開いたときに同じデータを何度も取りに行かないようにしました。
- 最初に必要なものだけ読み、Excel出力・クイック編集・案内ツアーなどは使うときだけ読みます。
- 画面の文字や見た目の読み込みも整理し、待ち時間を減らしました。

**案件詳細**

- 開いた直後にまとめて読んでいた部品（編集用エディタやコメントなど）を、必要なタイミングまで後ろに回しました。
- 同じ部品を二重に読み込んでいたところをやめました。
- 担当者名や作業量の表示用に、重いデータの代わりに軽い取り方に切り替えました。
- 関係するデータを、できるだけ同時に取りに行くようにしました。
